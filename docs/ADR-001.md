# ADR-001: Idempotent approval APIs with retry

## Context
Approval flows retry on transient failures; duplicate approvals are unacceptable.

## Decision
All mutating endpoints accept idempotency keys; transient AI calls use exponential
backoff; high-risk decisions always route to humans.

## Consequences
- Safe retries without double approvals.
- Idempotency store must become durable (Dataverse/Redis) in production.
